Detailed Description

template<typename MeshType_, typename WeightType_>
class FEAT::Control::Domain::DeslaggingPredicateBase< MeshType_, WeightType_ >

Abstract base class for deslagging predicates.

Deslagging predicates are used by the DeslaggedDomainControl to decide which parts of the mesh to keep and which parts to discard.

pure virtual

Gathers the element slag weights for a given mesh.

The "slag weight" of an element is defined as the area of the element inside the domain divided by the total area of the element.

Parameters
[in]meshThe mesh for which the element weights are to be gathered.
Returns
A vector of floats in range [0,1] representing the element slag weights on the mesh. The length of the vector corresponds to the number of elements of the mesh.
