Detailed Description

template<typename DT_, typename IT_, int NR_, int NC_>
struct FEAT::Solver::RichardsonHelper::MetaMatrix< DT_, IT_, NR_, NC_ >

A whole meta matrix as a constexpr NR_ x NC_ grid of (possibly empty) BCSR blocks.

The grid dimensions are compile-time known (the meta layout is fixed), so the container uses a std::array. Blocks are stored row-major: blocks[r*NC_ + c] is the (r,c) meta-block, which maps source vector component c to target vector component r.
