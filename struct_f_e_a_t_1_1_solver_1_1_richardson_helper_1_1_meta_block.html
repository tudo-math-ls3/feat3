Detailed Description

template<typename DT_, typename IT_>
struct FEAT::Solver::RichardsonHelper::MetaBlock< DT_, IT_ >

A single (k x l) BCSR meta-block, referenced by its data arbiters.

A grid cell may be "empty" (val == nullptr or num_nnz == 0), in which case the host driver skips it entirely (no kernel launch). This is how the structurally-zero blocks of a saddle-point system (and the numerically-empty pressure-pressure block of the AmaVanka inverse) cost nothing, without the kernel ever special-casing the matrix structure.

The size fields (num_rows, num_cols, num_nnz) are block counts, matching the LAFEM::SparseMatrixBCSR num_rows()/num_cols()/num_nzes() semantics expected by LAFEM::Arch::MatVecMultBCSRDense::exec_cuda_impl.
