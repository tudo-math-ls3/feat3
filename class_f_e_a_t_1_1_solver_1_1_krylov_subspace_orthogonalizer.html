Orthogonalizes v_[ti] against v_0,...v_{ti-1}.

Parameters
[out]dot_productA \transisitive array of size target_index in which the dot products should be written
[in]target_indexThe index of target inside the underlying vector array.
Returns
The euclid norm of the orthogonalized target
Note
target has to be in the vector array provided to this component.
You should always call this interface in a sequential manner regarding target_index, else the subspace is not guaranteed to be orthogonal
