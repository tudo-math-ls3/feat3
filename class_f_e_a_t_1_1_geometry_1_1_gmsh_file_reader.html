Detailed Description

Gmsh file reader class.

This class implements a reader which parses Gmesh's .msh files into a RootMeshNode.

The basic usage is as follows:

  1. Create an object of the GmshFileReader
  2. Scan through the file to ensure it contains a mesh that FEAT can represent using read_root_markup()
  3. Call the parse() function with the appropriate mesh type

For more details on meshes, see the related doxygen page FEAT Mesh File Format.

Limitations:

  1. Currently only nodes and elements are parsed. No charts, meshparts, or partitions will be created.
  2. Only the version 2.2 legacy format is supported.
  3. Only meshes with contiguous indices for vertices and elements are supported.

See Chapter 10 of https://gmsh.info/dev/doc/texinfo/gmsh.pdf for detail on the mesh format.
