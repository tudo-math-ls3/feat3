Detailed Description

template<typename Mesh_>
class FEAT::Assembly::FeatureMeshPartFactory< Mesh_ >

Factory for MeshParts describing features of the mesh boundary.

Features are parts of the boundary that should be left unchanged by geometric algorithms because they describe high frequency detail. This factory determines features by determining the angle between the normals of adjacent mesh facets. Entities shared by facets where that angle is larger than some critical angle are categorized as feature entities.

On a 2D mesh, this factory compares the normals of adjacent boundary edges. If the angle between the normals is larger than the critical angle, the shared vertex is considered a feature vertex.

On a 3D mesh, this factory compares the normals of adjacent boundary faces. If the angle between the normals is larger than the critical angle, the shared edge and the shared vertices are considered feature entities.
