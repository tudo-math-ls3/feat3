Detailed Description

template<typename Mesh_>
class FEAT::Assembly::ProjectionFilterAssembler< Mesh_ >

ProjectionFilter assembler class template.

Utility class for managing the Neumann boundary and boundary features, determining vertex kinds (Boundary, Feature, Fixed), and assembling ProjectionFilters.

Markus Muegge
