Detailed Description

template<typename DT_, typename IT_ = Index>
class FEAT::LAFEM::DenseMatrix< DT_, IT_ >

Dense data matrix class template.

Template Parameters
DT_The datatype to be used.
IT_The indexing type to be used.

This class represents a matrix of continuous data in memory.

Data survey:
_elements[0]: raw number values
_scalar_index[0]: row count
_scalar_index[1]: column count

Refer to lafem_design for general usage informations.

Author
Dirk Ribbrock
