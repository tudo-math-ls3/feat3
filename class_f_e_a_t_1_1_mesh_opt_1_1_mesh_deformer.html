Detailed Description

template<typename MeshType_>
class FEAT::MeshOpt::MeshDeformer< MeshType_ >

Deforms mesh towards target cell sizes.

Based on "Mathematical and Numerical Analysis of a Robust and Efficient Grid Deformation Method in the Finite Element Context" by Grajewski, Koester, and Turek (https://doi.org/10.1137/050639387) the MeshDeformer can deform a mesh towards a target cell size function. The mesh topology is left unchanged.

Author
Markus Muegge

◆ set_blend_steps()

template<typename MeshType_ >
void FEAT::MeshOpt::MeshDeformer< MeshType_ >::set_blend_steps ( Index  steps)
inline

Set number of blend steps.

Parameters
[in]stepsNumber of blend steps

The deformation depends on a good-enough solution to the Poisson problem created from the current cell sizes and the target cell sizes. If the difference between those function is too large, the deformer might produce widly degenerate meshes.

The blend steps split the deformation into multiple steps, where each steps monitor function is an interpolation between the current cell size function and the target monitor function. That way each step can solve a better conditioned Poisson problem and the mesh does not degenerate.

template<typename MeshType_ >
void FEAT::MeshOpt::MeshDeformer< MeshType_ >::set_max_iters_per_blend_step ( Index  iters)
inline

Sets the maximum number of iterations during each blend step.

Parameters
[in]itersMaximum number of iterations per blend step.

The deformation depends on a good enough solution to the Poisson problem created from the current cell sizes and the target cell sizes. We can improve the solution by re-assembling the Poisson-problem (with the same monitor function) on an already deformed mesh, solving that new problem, and deforming the mesh further according to that improved solution.

This sets the maximum number of such iterations. If the quality measure is already sufficiently good before reaching the maximum number of steps the deformer will continue to the next blend step (or finish, if it is on the last blend step already).
