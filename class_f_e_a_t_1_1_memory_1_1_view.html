Detailed Description

Raw memory view class.

This class represents a raw view for a (region of a bigger) memory block that is managed by the Memory::Arbiter class. This class stores a void pointer and the size of the memory block in bytes and it therefore does not offer any functionality related to array elements etc. as this class has no knowledge of how the data is to be interpreted.

If you need a view for a memory block that is interpreted as an (array of) object(s) of a certain data type or class, then consider the documentation of the Memory::TypedView class template, which is derived from this class.

See Memory Views, Locations and Access Rights for more information.
