Calculates the dot products of target with all members of vectors in a batched manner.

Parameters
[in,out]local_dotsThe Memory::Arbiter holding the dot-product results (values are added upon); the batched kernels acquire the host/device view they need from it, so it must already contain the zeroed or partially accumulated values.
[in]targetThe vector all dot products shall be calculated with
[in]vectorsAn array of memory arbiter objects for which the dot products shall be calculated
[in]sizeThe number of meta elements in vectors
[in]strideThe distance (in arbiters) between two consecutive meta-components of the same vector inside the flat vectors array, i.e. the per-component block size used by gather_arbiter (the total number of gathered vectors). Used to advance to the next tuple component; it is not equal to size.
Note
It is assumed that vectors hold the unpacked memory arbiter of the underlying classes, i.e. filled by the get_arbiter function.
It is assumed that local dots is allocated to the correct size
