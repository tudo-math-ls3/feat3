Detailed Description

Stack manager for nested NVTX profiling ranges.

Abstracts the paired Util::cuda_start_range / Util::cuda_stop_range calls behind a push/pop stack: push() opens a named range and stores its id, pop() closes the most recently opened one (LIFO). The destructor closes any ranges still open, so an early return or a thrown exception cannot leak a dangling range.

All operations are no-ops unless FEAT_HAVE_CUDA is defined.
