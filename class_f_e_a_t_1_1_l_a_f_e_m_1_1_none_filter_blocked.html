Detailed Description

template<typename DataType_, typename IndexType_, int block_size_>
class FEAT::LAFEM::NoneFilterBlocked< DataType_, IndexType_, block_size_ >

Blocked None Filter class template.

This class implements a filter that does nothing.

Note
Not to be confused with do-nothing boundary conditions.

Peter Zajac
