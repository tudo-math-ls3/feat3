Detailed Description

template<typename Matrix_, typename Filter_>
class FEAT::Solver::AmaVankaGMRES< Matrix_, Filter_ >

GMRES(k) solver implementation specialization for an Stokes typed GMRES(AmaVanka) implementation.

This GMRES variant is specialized with a vanka type preconditionier matrix and scalarizes the internal system which allows for very specific optimizations in combination with a kernel fusing of the main loop. Since this approach is memory heavy, it is recommended to only use this solver as a coarse grid solver for the case of many gpus or very small local system sizes. In alle other cases, the standard GMRES with the batched dot variants should be sufficient.

See also
Y. Saad: A flexible inner-outer preconditioned GMRES algorithm; SIAM Journal on Scientific Computing, Volume 14 Issue 2, pp. 461-469, March 1993
