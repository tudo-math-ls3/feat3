Detailed Description

MPI typemap description.

A typemap is a sequence of datatypes and displacements. MPI uses these typemaps to send and receive datatypes that are more general than the basic types MPI offers per default.

This class is deliberately MPI-agnostic, so that types can offer Typemaps of themselves without having to check if MPI is available.

struct Foo
{
Index i;
Real r[8];
};
Typemap foo_typemap = Typemap{}.add_entry<Index>(offsetof(Foo, i)).add_entry<Real>(offsetof(Foo, r), 8);
