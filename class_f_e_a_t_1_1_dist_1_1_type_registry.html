Detailed Description

Singleton for managing derived Datatypes.

This TypeRegistry singleton creates and stores derived MPI datatypes. Datatypes are created lazily the first time they are required.

Due to the lack of reflection in C++, C++ types need to provide a Typemap for themselves via the TypeDescription trait.
