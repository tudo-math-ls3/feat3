Detailed Description

template<typename MatrixType_>
class FEAT::Control::AFCTransportSolver< MatrixType_ >

An algebraic flux correction solver for the instationary scalar advection, diffusion, reaction equation.

This interface solves the equation given by \( M u + K u + L u + N u = f \\ u = g on \delta_+\Omega \) where \( M \) is the (lumped) mass matrix \( K \) is a convetion matrix \( L \) is a diffusion matrix \( N \) is a scaled mass matrix

Template Parameters
MatrixType_The matrix type to be used

◆ limit_stiff_matrix()

template<typename MatrixType_ >
void FEAT::Control::AFCTransportSolver< MatrixType_ >::limit_stiff_matrix ( bool  limit)
inline

Wether or not to also limit the stiffness matrix.

Depending on mesh quality and diffusion tensor it may happen that the stiffnes matrix has positive off diagonal elements, which can lead to the low order scheme not being bound preserving. To counteract this, you can choose to incorporate the sitffness matrix into the inital calculation of the artifical diffusion. This can lead to an order reduction, but the scheme shouldn't violate the initial boundaries

Should be set before calculating the artificial diffusion, i.e. before calling init_stepsize()
