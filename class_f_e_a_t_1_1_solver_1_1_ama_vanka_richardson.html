Detailed Description

template<typename Matrix_, typename Filter_>
class FEAT::Solver::AmaVankaRichardson< Matrix_, Filter_ >

Fused Richardson(Schwarz(AmaVanka)) smoother specialization for a global (meta) system.

This solver reproduces the classic Richardson(omega) preconditioned by Schwarz(AmaVanka) smoother stack, but fuses the whole per-step update \( u \gets u + \omega\, f(V\, f(b - A u)) \) into a single hand-synchronized device driver.

In contrast to AmaVankaGMRES (which flattens the meta system into one scalar CSR), this solver walks the (k x l) BCSR meta blocks natively via LAFEM::Arch::MatVecMultBCSRDense on device, so no scalar-CSR copy of the system is built.

Note
Phase 1 limitations (see helper/gotchas): only UnitFilter / UnitFilterBlocked DOFs are enforced on the device path (Slip/Mean filters are dropped, as in AmaVankaGMRES), and only the fixed-step mode (min_iter == max_iter, no residual norm) is supported on device. The generic (CPU) path applies the full system filter and is used as the reference.
