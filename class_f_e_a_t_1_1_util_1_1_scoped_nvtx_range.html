Detailed Description

RAII scope guard for an NVTX profiling range.

Built on top of NvtxRangeStack: opens a range on construction and closes it on destruction, so wrapping a scope in a range is a single line. Uses the calling thread's default stack unless an explicit stack is supplied.

All operations are no-ops unless FEAT_HAVE_CUDA is defined.
