Detailed Description

template<typename Adjactor_>
class FEAT::Adjacency::ImageRange< Adjactor_ >

Wrapper for using range-based for loops with adjactors.

Template Parameters
Adjactor_Adjactor type wrapped by this wrapper

This wrapper allows you to replace

for(auto it = adj.image_begin(n); it != adj.image_end(n); ++it)
{
const auto i = *it;
...
}

with

for(const auto i : Adjacency::ImageRange(adj, n))
{
...
}
