Detailed Description

template<typename R_, typename... Args_>
class FEAT::Global::ScalarRemoteLambda< R_(Args_...)>

MPI-abstraction for running scalar lambdas on other ranks.

Template Parameters
R_Return type of the lambda function
Args_Parameter-pack of argument types of the lambda function

This class-template allows calling scalar lambda functions on other ranks. We call a lambda function scalar if it returns a single MPI-transmittable type.

See also
RemoteLambda<Range_<R_>(Args_...)> for the specialization for vector-valued lambdas

Remote lambda call.

Template Parameters
RankRange_Range of ints, must have begin and end methods.
IndexRange_Range of Index, must have begin and end methods.
ArgsRange_Range of argument tuples Range of ArgumentTupless, must have begin and end methods.
Lambda_Type of lambda function. Must be compatible with ReturnType and ArgumentTuple
Parameters
[in]ranksRange of ranks, for each entry a remote call will be made to that rank
[in]indicesRange of indices, must have same size as ranks and contain valid indices into the args range
[in]argsRange of argument tuples
[in]lambdaLambda function to call on this rank
Returns
A vector containing the return values of all calls described by ranks, indices, and args, in the same order.

Assume we have ranges ranks, indices, and args. Assume result = remote_lambda.call(ranks, indices, args, lambda) for some remote_lambda and some lambda. Let n be the size of ranks. Then for 0 <= i < n: result[i] = lambda(args[indices[i]])
