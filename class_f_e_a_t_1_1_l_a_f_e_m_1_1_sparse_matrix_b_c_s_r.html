Detailed Description

template<typename DT_, typename IT_, int block_height_, int block_width_>
class FEAT::LAFEM::SparseMatrixBCSR< DT_, IT_, block_height_, block_width_ >

CSR based blocked sparse matrix.

Template Parameters
DT_The datatype to be used.
IT_The indexing type to be used.

This class represents a sparse matrix, that stores its non zero elements in the compressed sparse row format. Every non zero element is a small dense matrix block on itself, represented as Tiny::Matrix objects. To be consistent with the external interface, the layout information are stored in block-scoped coordinates.

Data survey:
_elements[0]: raw non zero number values
_indices[0]: row start index (including matrix end index)
_indices[1]: column index per non zero element
_scalar_index[0]: row count
_scalar_index[1]: column count
_scalar_index[2]: non zero element count (used ValueType elements)
Refer to lafem_design for general usage informations.

Author
Dirk Ribbrock
