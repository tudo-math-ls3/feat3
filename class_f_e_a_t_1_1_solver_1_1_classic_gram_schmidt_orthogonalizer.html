Detailed Description

template<typename Vector_>
class FEAT::Solver::ClassicGramSchmidtOrthogonalizer< Vector_ >

Abstraction of the classical Gram-Schmidt procedure with a batched reduction.

In contrast to the modified Gram-Schmidt procedure, the classical variant computes all inner dot products of the target vector against the existing basis vectors independently, which allows them to be evaluated in a single batched reduction (and thus a single global all-reduce in the distributed case) instead of one reduction per basis vector.

In addition, the self-dot \(\langle w, w\rangle\) is appended to the same batched reduction, so the euclidean norm of the orthogonalized target can be recovered algebraically as \(\sqrt{\langle w,w\rangle - \sum_k h_k^2}\) without a separate norm2 reduction. The algebraic norm is only trusted while it stays safely positive; on heavy cancellation we fall back to an explicit norm2, which guarantees a positive result so the subsequent normalization cannot produce a NaN.

Computes the batched dot products of target against the leading basis vectors.

A single batched reduction fills dots_out[0..num_basis) with \(\langle \text{target}, v_k\rangle\) and returns the self-dot \(\langle \text{target}, \text{target}\rangle\) (basis slot num_basis) in self_dot.

Parameters
[in]targetThe vector all dot products are computed with.
[in]num_basisThe number of leading basis vectors to project against.
[out]dot_outA host array of size num_basis receiving the inner dot products.
[out]self_dotReceives the self-dot of target.
