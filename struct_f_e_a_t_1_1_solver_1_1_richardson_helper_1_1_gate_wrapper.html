Detailed Description

template<typename DT_, typename IT_>
struct FEAT::Solver::RichardsonHelper::GateWrapper< DT_, IT_ >

Per-meta-row (per-component) gate for the hand-rolled synchronization.

One GateWrapper per meta component/row. A component whose ranks is empty needs no synchronization (e.g. a discontinuous pressure space) and its sync is a no-op — which lets the driver overlap the halo exchange of the components that do need it with the compute of those that do not. All components of a saddle-point system share the same scalar shared-node mirror indices, but each carries its own here to keep the interface fully general.
