Computes the voxel map based on a chart.

Attention
This function is a "collective" function in distributed parallel (i.e. MPI) simulations and each process must be given the same chart, because this function distributes the actual work over all processes before gathering the computed voxel map on all processes afterwards!
Parameters
[in]commA communicator to distribute work over. If the voxel map is smaller than the given communicator a appropriate sub-communicator will be created automatically.
[in]chartA transient reference to the chart that is to be used for the inside outside test.
[in]invertSpecifies, whether the definition of inside/outside is to be inverted.

Computes the voxel map based on a surface triangulation stored in an OFF file.

Note
This function can only be used in 3D and if FEAT was compiled and linked against the CGAL library.
Attention
This function is a "collective" function in distributed parallel (i.e. MPI) simulations and each process must be given the same OFF file content stream, because this function distributes the actual work over all processes before gathering the computed voxel map on all processes afterwards!
Parameters
[in]commA communicator to distribute work over. If the voxel map is smaller than the given communicator a appropriate sub-communicator will be created automatically.
[in]isThe input stream that contains the OFF data; this should ideally be a std::stringstream that was read in by using the DistFileIO::read_common function to avoid a DDoS attack on the file system.
[in]invertSpecifies, whether the inside/outside is to be inverted.
