Detailed Description

template<typename DT_, typename IT_ = Index>
class FEAT::LAFEM::SparseMatrixCSCR< DT_, IT_ >

CSCR based sparse matrix.

Template Parameters
DT_The datatype to be used.
IT_The indexing type to be used.

This class represents a sparse matrix, that stores its non zero elements in the compressed sparse compressed row format.
This format is very similar to the standard CSR format but stores explicit row numbers for each non empty row.

Data survey:
_elements[0]: raw non zero number values
_indices[0]: row start index (including matrix end index)
_indices[1]: row number of each non empty row
_indices[2]: column index per non zero element
_scalar_index[0]: row count
_scalar_index[1]: column count
_scalar_index[2]: non zero row count _scalar_index[3]: non zero element count (used elements)
Refer to lafem_design for general usage informations.
